## Ce que c'est
- **Pour les groupes et artistes** : publiez vos sorties, vidéos et communiqués, gratuitement.
- **Pour les fans** : découvrez des groupes, écoutez directement dans les publications (Spotify, Bandcamp, Apple Music).
- **DFlow Radio** : la web radio du réseau.

## Envoyez-nous vos promotions
Groupes, labels, agences : envoyez vos communiqués ; nous les publions sur genia.social et nos réseaux.
